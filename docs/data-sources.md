# Launch data sources

## Workshop directory source

The launch directory is sourced from public Google Maps business listings collected for South African mechanic-related searches in major cities.

### Query set used for launch curation

- `car mechanic Johannesburg South Africa`
- `car mechanic Cape Town South Africa`
- `car mechanic Durban South Africa`
- `car mechanic Pretoria South Africa`
- `car mechanic Gqeberha South Africa`
- `car mechanic Bloemfontein South Africa`

## Pricing beta source

The current Fair Price Index beta uses the public sample currently visible on The Bonnet homepage for VW Polo brake pad replacement.

## Important notes

- This launch dataset is a curated starting point, not the final long-term ingestion pipeline.
- Opening hours, phone numbers, website links, and rating values were taken from the public source listings used for launch curation.
- Review counts, warranties, and deeper service metadata should only be published later when collected from first-party or verified sources.
